# Security Policy

## Supported Versions


| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:  |

## Reporting a Vulnerability

In order to report a vulnerability it is enought to create an issue in GitHub issue.
Include:
   - A clear description of the vulnerability.
   - Steps to reproduce the issue (proof of concept if possible).
   - The impact and any known workarounds.

Please read [CONTRIBUTING.md](./CONTRIBUTING.md) for other contributing suggestions.
